To **author and save** a workflow (nodes, edges, variables, sub-nodes, pointers), use **this** site:

| Resource | URL |
| -------- | --- |
| Build workflows cookbook | [Build a workflow](/build-workflows/overview) |
| Workflows REST | [List](/api-reference/workflows/get-minimal), [get](/api-reference/workflows/get), [create](/api-reference/workflows/create), [update](/api-reference/workflows/update), [create folder](/api-reference/workflows/create-folder), [trigger](/api-reference/workflows/trigger), [reset analytics](/api-reference/workflows/analytics-reset) |
| MCP | [docs.pingmee.co.il/mcp](https://docs.pingmee.co.il/mcp) |

That MCP is sufficient. Register one server:

```json
{
  "mcpServers": {
    "pingmee-api": {
      "url": "https://docs.pingmee.co.il/mcp"
    }
  }
}
```

| Question type | Use |
| ------------- | --- |
| Create / GET / PUT a workflow, dual-graph JSON, variables, sub-nodes, pointers | `pingmee-api` (this site) |
| Bind a WhatsApp phone; fetch templates only for starter/outbound (or a named template) | [GET phone numbers](/api-reference/business/get-phone-numbers), [GET templates](/api-reference/business/get-templates) — [infer starter vs reply](/build-workflows/overview#infer-starter-vs-reply) |
| Analyze canvas analytics then improve the graph | GET `analytics` on the workflow, then PUT — [Workflow analytics](/build-workflows/analytics) |
| Board UI labels, form screenshots, Hebrew node guides | Optional Workflow Docs (below) |

## Optional — Workflow Docs (board UI)

[docs-workflows.pingmee.co.il](https://docs-workflows.pingmee.co.il/docs) is a human UI catalog (drawer, forms, screenshots). You do **not** need its MCP to build or save a graph.

| Resource | URL |
| -------- | --- |
| Documentation | [docs-workflows.pingmee.co.il/docs](https://docs-workflows.pingmee.co.il/docs) |
| LLM index (`llms.txt`) | [docs-workflows.pingmee.co.il/llms.txt](https://docs-workflows.pingmee.co.il/llms.txt) |
| Full corpus (`llms-full.txt`) | [docs-workflows.pingmee.co.il/llms-full.txt](https://docs-workflows.pingmee.co.il/llms-full.txt) |
| MCP (optional) | [docs-workflows.pingmee.co.il/mcp](https://docs-workflows.pingmee.co.il/mcp) |

What's on Workflow Docs: trigger/action/condition form copy, nodes drawer, board toolbar, sticky notes. English and Hebrew (`/docs` and `/he/docs`).

If you add the optional MCP:

```json
{
  "mcpServers": {
    "pingmee-api": {
      "url": "https://docs.pingmee.co.il/mcp"
    },
    "pingmee-workflows": {
      "url": "https://docs-workflows.pingmee.co.il/mcp"
    }
  }
}
```

Workflow Docs tools: `search_workflows`, `query_docs_filesystem_workflows`, `list_pages`.

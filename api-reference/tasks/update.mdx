---

Partial update — send only the fields you want to change. For example, to update title and status:

```json
{
  "title": "Call back tomorrow",
  "statusCase": "standby"
}
```

Updatable fields: `title`, `body`, `statusCase`, `assignedAgentIds`, `viewedByAgentIds`, `dueDate`, `participantsIdentifiers`, `phoneNumberId`.

The server always refreshes `updatedAt` and `agentIdentification`, and increments `unreadCount`.
